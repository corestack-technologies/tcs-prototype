# TCS v1 API Requirements

TCS Prototype v1 production handoff. Requirements describe the approved build contract, not infrastructure already delivered.

Action-oriented capability catalogue, not REST paths or OpenAPI. Multiple operations in a row share a domain contract; production API design must retain each action's guards. Derive actor/tenant from trusted authentication, not request-supplied persona. All money uses integer minor units and explicit currency. Error results distinguish validation, forbidden, stale/conflict, unavailable integration and retryable transport failure without leaking private source data.

| A21 / Settings | Read controls/history/diagnostics; preview/apply runtime or Business Date change | Explicit Settings roles | Key/value/date/reason/version → preview/change/history | settings.view plus exact action; production controlled date denied; protected history | Revision/actor-bound preview; change key |
| A22 / Scheduled Processes | Read definitions/run history; preview/run; retry failed run | Explicit process roles | Definition/target/reason/expected source → run/steps/errors | View/run/retry distinct; current authority; environment guard and lock | Durable run key, domain keys and linked retry; preserve partial success |
| A23 / Notifications | Record committed event, select consented channels, send/retry adapter delivery, ingest status, read own history/preferences | Domain event worker; recipient | Event/template/recipient/consent → delivery history/status | Service authority; recipient scope; signed provider callbacks; private content minimization | Event+recipient+template/channel dedupe; delivery attempts retained |

Production-only transport/persistence is required even where the prototype invokes an in-memory function. A15's real Recovery ingestion must connect approved payment infrastructure; the prototype does not provide a new Recovery rail. A07 must connect legacy discovery to actual recruitment. Do not implement an unrestricted CRUD API for ledger balances, permission arrays, case outcomes or immutable audit rows.
