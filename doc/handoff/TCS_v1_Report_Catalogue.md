# TCS v1 Report Catalogue

Frozen product extraction for TCS Prototype v1. Production requirements below are not implemented infrastructure.

All 32 final catalogue entries are listed below. Reports are read-only. Common filters include a period on the stated date basis plus each listed dimension and text search where exposed. Exports must contain only the same authorized filtered projection; preserve headers, money precision, null/unavailable values and formula-injection protection. The current export is CSV; do not invent a new report or export format.
