# TCS v1 Route / Screen Inventory

Frozen product extraction for TCS Prototype v1. Production requirements below are not implemented infrastructure.

There are 62 meaningful View identifiers, including compatibility aliases. Only the explicit HTTP paths below are recognized on initial load; other views use in-memory navigation and optional Group/Round/case metadata. HTTP fallback is not authentication. Production must supply durable URL/context routing and server authorization while retaining the journeys.

Responsive contract: every screen uses the shared responsive layout; mobile navigation collapses, forms stack, financial tables use contained overflow and dialogs fit the viewport with focus handling. Six-width structural coverage does not establish real-device visual approval.
